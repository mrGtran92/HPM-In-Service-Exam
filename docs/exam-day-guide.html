HPM In-Service Exam — Exam Day Guide

Keep the Google Sheet open on the Exam day tab. Every action is under the HPM Exam menu.

Running the exam

  1. Day before: Pre-exam check — all ✓. Then Turn tester access off.
  2. Fellows open the link and enter name + email. They'll see Code C ("not opened yet") — expected.
  3. When everyone is seated: Open exam. Fellows click Begin again.
  4. Watch Exam day: Not started → In progress (answered, last saved) → Submitted (score).
  5. After the last submission: Close exam. Results are in the Attempts tab.

Error codes on a fellow's screen

They seeDo this
REmail isn't on the exam listLikely a typo. Compare with the Roster tab; fix the roster if it's wrong. Click Begin again.
CExam hasn't been opened yetOpen exam.
SAlready submitted with this emailIf you allow it: Allow a retake… (they've already seen the answers).
BServer is busyWait 5 seconds, click Begin again.
NCan't reach the exam serverWi-Fi. Answers are safe on the laptop — keep working. If submit fails, see below.
VAttempt was reset by the proctorExpected after a retake. Reload the page and start again.
AAttempt not recognisedDownload answers if offered; reload; Begin again with the same email.
FExam isn't set upPublish exam version…
XSomething went wrong on the serverNote the message. Try again in a minute. Open the /exec link to check the server.

Common situations

Laptop dies / browser crashes. Open the link on any computer, same email → continues where they left off (a different computer may lose the last ~30 s).
Page won't load at all. That computer or its Wi-Fi. Try another browser or a spare laptop.
Submit failed. Fellow clicks Download my answers and gives you the file. Open it in TextEdit → select all → copy → Add a submission from a downloaded file… → paste.
Submitted by accident. Your call: Allow a retake… voids it (kept, marked void); they restart at Q1.
Tester link: exam address + #tester, with the code in Config › tester_code. Test runs are never counted.  ·  Log: every open, close, publish and retake is in AuditLog.
